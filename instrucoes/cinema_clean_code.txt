Desenvolva uma implementação em Python para um sistema de venda de ingressos de cinema com foco absoluto na legibilidade, manutenibilidade e aplicação estrita dos princípios SOLID, especialmente o Princípio da Responsabilidade Única (SRP) e o Princípio Aberto/Fechado (OCP). O sistema deve receber o valor base do ingresso, a idade do cliente, o dia da semana e o status de estudante para calcular o preço final, aplicando um desconto não-cumulativo de 50% se o dia for quarta-feira, se o cliente for estudante, se tiver até 12 anos ou se tiver 60 anos ou mais. Para atender aos critérios arquiteturais, a lógica de validação e aplicação das regras de desconto deve ser completamente isolada da estrutura de dados do ingresso, e o design deve ser extensível por meio de polimorfismo ou funções independentes, garantindo que novas regras de desconto futuras possam ser adicionadas criando novas classes ou componentes sem alterar o código existente, eliminando assim o uso de estruturas complexas de condicionais aninhados. Utilize tipagem estática (Type Hints), nomes altamente semânticos e apresente uma breve explicação de como o design escolhido reduz a complexidade ciclomática.
